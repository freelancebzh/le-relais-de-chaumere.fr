Développement Durable Publié le 11 octobre 2026

Notre site a passé le test de l'écologie numérique

Un site internet consomme de l'énergie : chaque page affichée fait travailler des serveurs, des réseaux et votre appareil. Pour un gîte qui veut limiter son impact, il aurait été curieux de l'oublier. J'ai donc fait mesurer ce site avec deux outils gratuits.

Ecoindex : note B, 77/100.
Sur la page d'accueil, l'outil relève environ 1,46 g d'équivalent CO₂ et 2,19 cl d'eau consommés par visite, pour 26 requêtes et 1,35 Mo de données. Ce n'est pas la note maximale : les photos pèsent forcément dans le total.
👉 Voir le résultat détaillé sur Ecoindex

Website Carbon : note B.
Cet autre outil estime les émissions de carbone d'une page vue. Là encore, le site se place bien, sans être parfait.
👉 Voir le résultat sur Website Carbon

Ce qui aide déjà :

  • des photos converties en WebP, un format plus léger ;
  • des images chargées seulement quand on arrive dessus ;
  • un site simple, sans gros outil ni extension inutile ;
  • des statistiques de visite qui ne se lancent qu'avec votre accord.

Les deux badges sont maintenant affichés en bas de chaque page. Je continuerai à alléger le site quand c'est possible, et je referai le test pour voir ce que cela change.
